# s21_stringplus

## Описание

`s21_stringplus` — это реализация собственной библиотеки для работы со строками на языке **C**.

Проект повторяет функциональность стандартной библиотеки:

```
<string.h>
```

а также реализует аналоги функций форматированного ввода-вывода:

```
sprintf
sscanf
```

Все функции реализованы **без использования стандартных строковых функций**, что позволяет глубже понять:

* работу с указателями
* управление памятью
* обработку строк
* парсинг форматированных строк
* работу со спецификаторами формата

Основная реализация находится в папке **`src`**.

# Реализованные функции

## Аналоги `<string.h>`

### Работа со строками

* `s21_strlen` — вычисляет длину строки
* `s21_strcpy` — копирует строку
* `s21_strncpy` — копирует строку с ограничением
* `s21_strcat` — объединяет строки
* `s21_strncat` — объединяет строки с ограничением

### Сравнение строк

* `s21_strcmp` — сравнение строк
* `s21_strncmp` — сравнение строк с ограничением

### Поиск

* `s21_strchr` — поиск символа
* `s21_strrchr` — поиск последнего вхождения символа
* `s21_strstr` — поиск подстроки
* `s21_strpbrk` — поиск любого символа из набора

### Работа с памятью

* `s21_memcpy`
* `s21_memmove`
* `s21_memset`
* `s21_memchr`
* `s21_memcmp`

### Дополнительные функции

Дополнительные утилиты для обработки строк:

* `s21_to_upper` — перевод строки в верхний регистр
* `s21_to_lower` — перевод строки в нижний регистр
* `s21_insert` — вставка подстроки
* `s21_trim` — удаление символов по краям строки

# Форматированный вывод

### `s21_sprintf`

Аналог функции:

```
sprintf
```

Поддерживает основные спецификаторы:

* `%d`
* `%i`
* `%u`
* `%f`
* `%c`
* `%s`
* `%x`
* `%X`
* `%o`
* `%p`
* `%%`

Также реализованы флаги и параметры форматирования:

* ширина (`width`)
* точность (`precision`)
* флаги (`+`, `-`, `0`, `#`, `space`)
* длины (`h`, `l`, `L`)

# Пример использования

```c
#include "s21_string.h"
#include <stdio.h>

int main() {
    const char *input = "25 3.14 hello";
    
    int a;
    float b;
    char str[50];

    s21_sscanf(input, "%d %f %s", &a, &b, str);

    printf("Integer: %d\n", a);
    printf("Float: %.2f\n", b);
    printf("String: %s\n", str);

    return 0;
}
```

### Что делает этот пример

Строка

```c
"25 3.14 hello"
```

разбирается функцией `s21_sscanf` по формату:

```c
"%d %f %s"
```

* `%d` → считывает целое число (`25`)
* `%f` → считывает число с плавающей точкой (`3.14`)
* `%s` → считывает строку (`hello`)

После выполнения значения будут записаны в переменные:

```
a = 25
b = 3.14
str = "hello"
```

и программа выведет:

```
Integer: 25
Float: 3.14
String: hello
```
